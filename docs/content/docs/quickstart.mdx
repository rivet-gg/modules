Use agentOS as a library to run VMs inside your own Node.js process. To create
durable VMs by ID and control them over HTTP instead, see the
[hosted quickstart](/agentos/docs/quickstart-hosted).

## Which one should I use?

|  | [Library](/agentos/docs/quickstart) | [Hosted](/agentos/docs/quickstart-hosted) |
|---|---|---|
| **Runs** | Inside your Node.js process | As the prebuilt `agentOS` Rivet Actor |
| **Package** | `@rivet-dev/agentos-core` | `@rivet-dev/agentos`, or plain HTTP |
| **VM identity** | A handle your process owns until `dispose()` | A durable VM you create by key and reach by ID |
| **Configuration** | Passed to `AgentOs.create()` | Stored with the VM and versioned |
| **Clients** | Your backend | Your backend, or browsers with a scoped JWT |
| **Host access** | Host functions, host mounts, external sandboxes | None; configuration is serializable only |
| **Previews** | None | Expiring preview URLs |
| **Best for** | Embedding VMs in an existing backend | Long-lived VMs shared across clients |

```bash
npm install @rivet-dev/agentos-core
```
