`@rivet-dev/agentos-core` runs VMs inside your Node.js process. Your
application owns VM identity, persistence, and lifecycle, and
`AgentOs.create()` returns a VM handle directly.

## Install

```bash
npm install @rivet-dev/agentos-core
```

The VM remains active until `dispose()` is called. Its filesystem is in memory
by default; see [Persistence](/agentos/docs/persistence) to keep files across VM
recreation.

## Configuration

The embedding process is trusted, so it can also give the VM access to host
resources:

- [host functions](/agentos/docs/host-functions) implemented as in-process callbacks;
- host-directory and other [mounts](/agentos/docs/filesystem#mounts);
- local `.aospkg` paths;
- explicit ownership of a shared sidecar process.
