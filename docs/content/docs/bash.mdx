Run bash inside the VM. Shell commands are the simplest agentOS execution
surface, and share the same execution lifecycle as JavaScript, TypeScript,
Python, and package workflows.

- **Hosted `v1.process.run`** takes an executable and an argument array. Run
  `sh` with `-c` for pipes, redirects, and globs.
- **Library `process.exec()`** runs a bash command line, and
  **`process.execFile()`** runs an executable whose arguments are never parsed
  by a shell.
- **In-VM only**: Commands run inside the VM, never in the host shell.

For multi-step work, consider [JavaScript](/agentos/docs/javascript) or
[Python](/agentos/docs/python) instead. One call returns real data structures
instead of a chain of shell calls.

## Run commands

<CodeGroup>

```ts Hosted @nocheck
import { createAgentOsClient } from "@rivet-dev/agentos";

const client = createAgentOsClient({ endpoint: "https://api.rivet.dev" });
const vm = client.agentOS.getOrCreate(["my-vm"]);

// Pipes, redirects, and globs need a shell, so run `sh -c`.
const piped = await vm.v1.process.run({
	command: "sh",
	args: ["-c", "echo 'hello world' | tr a-z A-Z"],
	options: { captureStdio: true },
});
console.log(piped.stdout.trim()); // "HELLO WORLD"

// Arguments are passed verbatim, so nothing is parsed by a shell.
const raw = await vm.v1.process.run({
	command: "echo",
	args: ["$(whoami)"],
	options: { captureStdio: true },
});
console.log(raw.stdout.trim(), raw.status.exitCode); // "$(whoami)" 0
```

## Background and interactive work

`spawn` starts a long-lived process and returns a handle. From there you get
stdin, a PTY, output replay, signals, and waiting.

<CodeGroup>

```ts Hosted @nocheck
import { createAgentOsClient } from "@rivet-dev/agentos";

const client = createAgentOsClient({ endpoint: "https://api.rivet.dev" });
const vm = client.agentOS.getOrCreate(["my-vm"]);

const shell = await vm.v1.process.spawn({ command: "sh", args: [] });

await vm.v1.process.stdin.write({ process: shell, data: "echo from the background\n" });
await vm.v1.process.stdin.close({ process: shell });

await vm.v1.process.wait({ process: shell });
const replay = await vm.v1.process.output.read({ process: shell });
console.log(replay.events.length);
```

## Files and software

Shell commands see the same [filesystem](/agentos/docs/filesystem) as
JavaScript and Python. Common POSIX commands ship by default; more is
projected through the [software registry](/agentos/docs/software).

<CodeGroup>

```ts Hosted @nocheck
import { createAgentOsClient } from "@rivet-dev/agentos";

const client = createAgentOsClient({ endpoint: "https://api.rivet.dev" });
const vm = client.agentOS.getOrCreate(["my-vm"]);

await vm.v1.process.run({
	command: "sh",
	args: ["-c", "printf 'a\\nb\\nc\\n' > /workspace/out.txt"],
});

const lines = await vm.v1.process.run({
	command: "sh",
	args: ["-c", "cat /workspace/out.txt | wc -l"],
	options: { captureStdio: true },
});
console.log(lines.stdout.trim()); // "3"
```
