---
title: "Browser Automation"
description: "Run a packaged browser CLI as ordinary agentOS software."
---

Browser automation is ordinary VM software. Install a browser CLI package, such
as Browserbase from the [registry](/agentos/docs/registry), at boot or with
`software.install`, then run it like any other command. See
[Software](/agentos/docs/software).

The guest receives only the credentials explicitly passed to the process
environment. agentOS does not provide a browser-specific API.

For workloads that need a full local browser, mount an
[external sandbox](/agentos/docs/sandboxes) and run the browser there.
