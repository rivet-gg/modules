---
title: "Persistence"
description: "Persist an agentOS VM's filesystem in SQLite so files survive VM recreation."
---

By default, a VM's root filesystem is an in-memory overlay over the bundled
base image. Its files are discarded when the VM is disposed.

To keep files across VM recreation, give the VM a SQLite `database` and store
its root filesystem there with the `chunked_sqlite` plugin. A new VM created
with the same options sees the same files.

`database` on its own stores Core and filesystem metadata, but does not make
the default in-memory root durable. A SQLite-backed root starts without the
bundled base image's files.

Persisted filesystems survive VM recreation. Running processes, terminals,
language contexts, open streams, cron jobs, and live subscriptions do not.

Core durable state uses `agentos_core_*` tables and filesystem storage uses
`agentos_fs_*`. Each owner has an independent schema version and migration
transaction.

The embedding application owns VM identity and decides when to recreate or
dispose the VM.
