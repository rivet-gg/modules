agentOS software ships as immutable `.aospkg` packages containing real compiled
tools. Installed packages are projected read-only under
`/opt/agentos/pkgs/<name>/<version>`, and their commands are linked under
`/opt/agentos/bin`. Every VM includes a default bundle with `sh`, coreutils, and
the standard CLI tools programs rely on. Pass `defaultSoftware: false` for a bare
VM with only the software you list.

Browse the available packages in the [registry](/agentos/docs/registry).

## Install at boot

Pass packages in `software` when creating the VM. Each entry is a
`{ packagePath }` reference to a packed `.aospkg` file, which is what the
`@agentos-software/*` packages in the agentOS repository export.

## Install while running

`software.install` adds a package to a running VM. The source is either a remote
HTTPS URL or a trusted local path, each with an optional exact
`sha256:<64 lowercase hex>` digest. New commands are available on
`/opt/agentos/bin` as soon as the call returns.

<CodeSnippet file="examples/embedded/software-install.ts" />

- `software.install(source)` returns the installed package's `packageId`,
  `digest`, `sizeBytes`, `packageName`, `version`, and `commands`.
- `software.uninstall(packageId)` removes a package installed through
  `software.install` and its command links.
- `software.installed()` lists packages installed through `software.install`.
- `software.list()` reports every package that provides commands in the VM,
  including boot-time and default software.

Only one software or mount mutation runs at a time per VM. A concurrent call
fails with `invalid_state` instead of queueing.

## Verification and caching

The sidecar downloads a URL source under strict size, time, and redirect
limits, verifies the bytes against the expected digest when one is given, and
validates the package format before projecting it. The verified content digest
is the package identity.

Packages are cached per sidecar process by content digest, so VMs that share a
sidecar reuse one verified copy. Repeat installs of the same bytes skip the
download, and the bytes are always verified before projection.

Registry software is not installed from npm. Releases upload digest-addressed
`.aospkg` files and a manifest to object storage; see
[Publishing Software](/agentos/docs/custom-software/publishing).

## Embedded API

The embedding process is trusted, so `software.install` accepts local package
paths as well as URLs. Read more in the
[embedded API quickstart](/agentos/docs/quickstart-embedded).
