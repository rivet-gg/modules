`@rivet-dev/agentos-core` runs agentOS VMs inside your Node.js process. Your
application owns VM identity, persistence, and disposal. Its native sidecar and
platform package must match the installed agentOS version. If resolution
reports a missing or mismatched binary, reinstall the packages;
`AGENTOS_SIDECAR_BIN` can select a custom local build.

## Trusted host capabilities

Because the embedding process is trusted, Core accepts values that run in or
read from the host:

- [host functions](/agentos/docs/host-functions);
- host-directory and other [mount plugins](/agentos/docs/filesystem#mounts);
- [external sandboxes](/agentos/docs/sandboxes);
- local `.aospkg` paths;
- custom schedule drivers and sidecar placement.

## Sidecar placement

VMs share a pooled sidecar process by default. Create a dedicated sidecar with
`AgentOs.createSidecar()` and pass it as `sidecar: { kind: "explicit", handle }`
to isolate a group of VMs or configure process-wide limits.
